# Data Flow Testing

## Deskripsi
Data Flow Testing adalah teknik white box testing yang berfokus pada aliran data atau variabel di dalam program. Pengujian ini dilakukan untuk mengetahui kapan variabel dibuat, digunakan, dan diproses.

## Keterangan
- D = Definition, yaitu variabel dibuat atau diberi nilai.
- U = Use, yaitu variabel digunakan.
- P-Use = variabel digunakan dalam kondisi percabangan.
- C-Use = variabel digunakan dalam proses penyimpanan atau perhitungan.
