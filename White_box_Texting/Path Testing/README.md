# Path Testing

## Deskripsi
Path Testing adalah teknik white box testing yang digunakan untuk menguji jalur-jalur independen dalam program. Jalur independen biasanya diperoleh dari struktur percabangan dan dihitung menggunakan Cyclomatic Complexity.

## Rumus Cyclomatic Complexity

V(G) = E - N + 2

Keterangan:
- E = jumlah edge
- N = jumlah node
- V(G) = jumlah jalur independen
