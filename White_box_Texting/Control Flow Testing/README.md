# Control Flow Testing

## Deskripsi
Control Flow Testing adalah teknik white box testing yang digunakan untuk menganalisis alur eksekusi program dari awal hingga akhir. Pengujian ini dilakukan untuk mengetahui jalur proses program, percabangan, dan alur kontrol yang terjadi pada sistem.
